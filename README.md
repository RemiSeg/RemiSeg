<h2 align="center">🚀 Selected Projects</h2>

### [Orchestraml](https://github.com/RemiSeg/Orchestraml)

Distributed job-orchestration platform built in **OCaml**, featuring transactional scheduling, worker heartbeats, retries, automatic reassignment, durable logs, PostgreSQL persistence, HTTP APIs, and Docker execution.

### [Fintech Portfolio](https://github.com/RemiSeg/Fintech_Portfolio)

Full-stack portfolio analytics platform using **Spring Boot, Vue and PostgreSQL**, with real market-data integration, portfolio management, performance metrics, and comparison tools.

### [CheECSEManager](https://github.com/F2025-ECSE223/ecse223-group-project-p16)

Team software-engineering project developed at McGill using **Java, Umple, Cucumber and Gherkin**, covering domain modelling, state machines, persistence, controllers, testing, and a complete GUI application.

### [CPU Design & ARMv7 Assembly](https://github.com/RemiSeg/CPU_Desing-ARMv7_Assembly)

Collection of low-level projects covering CPU design, **ARMv7 assembly**, interrupt-driven I/O, embedded programming, and C/assembly integration.

### [Poker Bot Arena](https://github.com/RemiSeg/Poker-tournament)

Full-stack Texas Hold'em engine and simulation environment for implementing and comparing different poker-bot strategies using **Java, Spring Boot, Vue and TypeScript**.

### [ATS Practice](https://github.com/RemiSeg/ATS_Practice)

Full-stack applicant-tracking and CV-matching proof of concept using **Spring Boot, PostgreSQL, Vue and local LLM integration**.
